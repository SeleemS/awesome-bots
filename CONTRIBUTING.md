# Contributing to Awesome Bots

Thank you for considering contributing to **Awesome Bots**! This list is community-driven — every addition makes it more useful for everyone.

## How to Contribute

### 1. Add a Bot

To suggest a new bot, open a **pull request** with the following:

- **Name** and **link** to the bot's website or repository
- **Category** — which section it belongs to (AI Assistants, Coding Agents, Web Crawlers, etc.)
- **Description** — one clear sentence about what it does
- **Pricing** — free (🆓), commercial (💰), open source (🔓), or managed (☁️)
- **Verification status** — if from bots.fyi, note if it's verified or unverified

### 2. Format

Follow the existing table format:

```markdown
| [Bot Name](https://example.com) ⭐ 🆓 | Category | Brief description of what it does |
```

### 3. Quality Guidelines

- **No duplicates** — check the list before adding
- **Working links** — verify the URL is live
- **Honest descriptions** — no marketing fluff
- **Correct category** — place it where users will find it
- **One bot per PR** — keep changes atomic and reviewable

### 4. Fix Something

- Broken link? Open an issue or PR with the fix
- Wrong description? Correct it directly
- Bot shut down? Let us know so we can remove it

## Style Guide

- Use the badge system: ⭐ 🔓 💰 ☁️ 🆓 🏢 🎯 ✅
- Keep descriptions under 100 characters in tables
- Link to the bot's official page, not a third-party review
- Use HTTPS URLs only

## Reporting Issues

- **Broken link** — paste the URL and what it should be
- **Wrong info** — describe the correction
- **Suggestion** — describe the bot and why it belongs here
